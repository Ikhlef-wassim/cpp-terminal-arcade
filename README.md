# C++ Terminal Arcade: Rogue Crawler

A lightweight 2D ASCII Rogue-style Dungeon Crawler engine written entirely in standard C++.

## Features
- Real-time immediate mode terminal character keyboard mapping mapping loops
- High-efficiency programmatic layout collision grid bounding arrays
- Independent localized file runtime with zero heavy framework configuration requirements

## Compilation and Local Execution
Compile and run the binary locally on macOS with a single line of text:
```zsh
clang++ -Wall -Wextra -std=c++17 main.cpp -o crawler && ./crawler
```
